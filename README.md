# Храбрый Воробей

Браузерная 2D-аркада в Преображенском парке Абакана. Волны бесконечны: 3, 5, 8, 13… голубей. До четырёх врагов на экране, остальные выходят по мере освобождения места.

Node.js 22+. Установка зависимостей не требуется.

```sh
npm start
```

Открыть http://localhost:4173. Телефон должен быть в одной локальной сети с компьютером: адрес компьютера и порт 4173, горизонтальная ориентация.

Управление: A/D или стрелки — движение; пробел — прыжок; J/K — клюв; Esc/P — пауза. На телефоне — кнопки двумя пальцами. Удержание клюва повторяет удары. Над головой атакующего голубя появляется «!».

Три сердца. Рекорд хранится только в текущем браузере. «Тренировка» не расходует сердца и не меняет рекорд; в ней можно настраивать дальность и частоту клевка.

Звук включается после нажатия «Защитить скамейку» или «Потренироваться»: фоновая музыка, клевки, попадания и курлыканье голубей. Кнопка ♫ выключает весь звук. На паузе и в главном меню боевой звук останавливается. Все звуки синтезируются локально, загрузка аудиофайлов не нужна.

«Звук и музыка» в главном меню и на паузе позволяет послушать и независимо выбрать тему и голос голубей. Темы: «Оборона парка» (132 BPM, боевой марш), «Налёт стаи» (152 BPM, погоня), «Последний рубеж» (116 BPM, мрачная оборона). Голоса: «Дозорный», «Нервная стая», «Вожак». Выбор сохраняется в браузере и применяется в бою. Нажатие «Слушать» включает звук, закрытие окна или уход с вкладки останавливает прослушивание.

```sh
npm test

```
