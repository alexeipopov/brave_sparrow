# Stack — 2026-11-15
- Canvas 2D рисует спрайты и эффекты; requestAnimationFrame задаёт цикл.
- Pointer Events дают независимые pointerId; pointer capture и pointercancel нужны для удержания нескольких кнопок.
- Web Audio запускается после действия пользователя; AudioContext.resume обрабатывается.
- Источники: https://developer.mozilla.org/en-US/docs/Web/API/Canvas_API/Tutorial
- https://developer.mozilla.org/en-US/docs/Web/API/Pointer_events
- https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API/Best_practices
- Вывод: native web, без внешнего runtime и CDN.
