# Playtests
## Agent QA — 2026-11-15
- 8 тестов логики: Фибоначчи после Number.MAX_SAFE_INTEGER, направление/высота/cooldown клевка, неуязвимость, прыжок, предел активных врагов, бесконечный переход, рекорды, улёт последнего врага.
- Независимый QA-агент проиграл модель до 7 волн: 3, 5, 8, 13, 21, 34, 55; Барон входит в число пятой волны.
- Chrome 1280×720: меню, управление клавиатурой, клевок, три победы и переход к волне 2, пауза.
- Chrome touch 844×390: две точки касания одновременно; отпускание снимает обе кнопки; кнопки 65–76 px; portrait → pause → resume.
- Прямой ?gym=1 работает без разрешения на звук; тренировка не сохраняет рекорд.
- Поражение, повтор с тремя сердцами, пауза при потере фокуса, чтение сохранённого/повреждённого рекорда проверены в Chrome.
- Экран результата целиком помещается на 844×390 и 568×320; обрезанная подсказка маленького меню скрыта.
- Исправлены зависание улетающей птицы при передышке, Space на кнопках меню и ожидание аудио при старте.
## User playtest
- 2026-11-15 — вопрос после предложения подойти к голубю, клюнуть и перепрыгнуть выпад: «Как ощущается бой?»
- Ответ пользователя дословно: «Удобно, темп подходит».
- Решение: M01 (движение, прыжок, клевок) locked; текущие параметры сохраняем.
- Устройство, опыт поздних волн и боя с Бароном не уточнялись; их проверку этот ответ не подтверждает.

## Audio QA — 2026-11-15
- 12 тестов прошли: 8 игровой логики + 4 аудио (блокировка autoplay, mute/pause/resume, синтез голубя, очистка узлов и ограничение полифонии).
- Chrome: измерен реальный сигнал Web Audio; музыка peak 0.087, во время боя 0.491; зарегистрированы два курлыканья.
- После mute, паузы и выхода в меню peak = 0; при возобновлении сигнал возвращается; ошибок JavaScript нет.
- Прямой ?gym=1 разблокирует звук первым нажатием; превью WAV находятся в локальной .runtime/.
- Баланс громкости на физическом телефоне и пользовательская оценка звучания пока не проверены.

## Audio variants — 2026-11-15
- Отзыв пользователя: «надо что-то более напряженное. воробей спасает парк все-таки».
- Сделаны три темы («Оборона парка», «Налёт стаи», «Последний рубеж») и три голоса («Дозорный», «Нервная стая», «Вожак»); при первом показе по умолчанию стояла первая пара.
- Пользователь выбрал дословно: «Налёт стаи — быстрая погоня». Тема swarm назначена по умолчанию; сохранённый вручную выбор в браузере имеет приоритет. Предпочтение по голосу голубей не задано.
- 14 тестов: полные музыкальные циклы всех вариантов, различия голосов, валидация сохранённого выбора, остановка старого трека; прежние проверки боя и аудио сохранены.
- Chrome: сигнал всех шести вариантов ненулевой и без клиппинга; смена темы, сохранение после reload, звук выбранной темы в бою, mute, закрытие/Escape/поворот телефона → тишина. Escape из звуковых настроек оставляет бой на паузе.
- Окно прослушивания визуально проверено при 1280×720, 844×390 и 568×320. Кнопки/списки не меньше 44 px и не обрезаны.
- Review выявил гонку ожидающего AudioContext.resume после потери фокуса; добавлена отмена ожидания и браузерная регрессия с отложенным resume.
- Скриншоты и шесть WAV-превью в .runtime/. На физических телефонах звучание ещё не проверено.
