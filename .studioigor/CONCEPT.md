# Храбрый Воробей — Concept
- [user] Браузерная 2D-аркада, вид сбоку, мобильный landscape, Преображенский парк Абакана.
- [user] Герой — воробей, враги — голуби, атака клювом; визуал references/brave-sparrow-concept.png.
- [user] Бесконечные волны: 3, 5, 8, 13…; никаких пяти волн до финала.
- [concept] Движение, прыжок, клевок, три сердца, отталкивание и короткая неуязвимость.
- [agent] Одна арена, три поведения голубей; Барон внутри каждой пятой волны. Цель — рекорд пройденных волн.
- Loop: подойти → клюнуть → отступить/перепрыгнуть → закончить волну → передышка.
- Pillars: управление двумя пальцами; враги предупреждают об атаке; персонажи читаются на фоне парка.
- Anti-pillars: без покупок, инвентаря и сетевой игры.
